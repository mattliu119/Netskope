IT 遠端連入：IP 換了之後用哪個 IP、由哪一區協助 IT remote access: which IP to use once it changes, and which region should help

遠端使用者的電腦出問題時，IT 要從機房端連進去協助。這一頁依 Hub Groups 文件裡的路由規則推論：Client 的 IP 來自它連上的那台 Hub、Hub 用 BGP 宣告 Pool 路由，以及 Failover 或使用者移動到其他地區時，Client 會連到另一台 Hub、換成另一個 IP。 When a remote user's laptop has a problem, IT connects in from the data center. This page infers from the routing rules in the Hub Groups document: the Client's IP comes from the Hub it joined, Hubs advertise pool routes via BGP, and on failover or when the user moves to another region the Client joins another Hub and gets another IP.
