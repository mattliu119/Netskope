Gmail 資料保護：用 CASB API 檢查信箱裡的郵件 Gmail Data Protection: CASB API inspects the mail in your mailboxes

不需要改郵件路由，也不需要安裝 Client。Gmail 透過 Pub/Sub 發出信箱變更通知，Netskope 以獲得全網域委派（domain-wide delegation）的服務帳號，用 Gmail API 讀取郵件與附件，交給 DLP 與 Email AI Security 檢查。違規的來信（inbound）與內部郵件可用 gmail.modify 移至垃圾桶；外寄郵件已送出，只能事後告警，要在寄出前阻擋仍需 SMTP Proxy。 No mail-routing changes and no Client. Gmail publishes mailbox notifications through Pub/Sub; Netskope uses a service account with domain-wide delegation to read messages and attachments through the Gmail API, checks them with DLP and Email AI Security. Violating inbound and internal email can be moved to trash with gmail.modify; outbound email has already left and can only be alerted on, so blocking before it leaves still needs the SMTP Proxy.
