資料外洩防護 (DLP) 本機與雲端聯動攔截流程 Endpoint DLP: Local Intercept & Cloud Inspection Workflow

檔案寫入網路共享（\\server\share）的 DLP 防護流程 DLP protection for files written to a network share (\\server\share)

使用者把檔案存到網路共享時，Netskope Client 的本機驅動先把檔案攔下來放在本機暫存區，送到 Netskope 雲端做 DLP 比對。命中敏感規則就刪除暫存檔、檔案不落地；檢查通過才正式寫入共享。事件以非同步方式上傳到 SkopeIT。 When a user saves a file to a network share, the Netskope Client's local driver holds it in a local temp area and sends it to the Netskope cloud for DLP inspection. If a sensitive rule matches, the temp file is deleted and nothing lands on the share; if it passes, the file is written. Events are uploaded to SkopeIT asynchronously.

02 · Technical Architecture Highlights

關鍵技術架構Key Architecture

本機驅動攔截與暫存Local Driver Intercept & Hold

寫往網路共享的檔案先由 Endpoint DLP 驅動（epdlpdrv）攔下，透明重定向到本機 Temp 目錄。Files written to a network share are caught by the Endpoint DLP driver (epdlpdrv) and transparently redirected to a local Temp folder.

  • 先檢查、後落地：判定前檔案不會寫到伺服器，不需要事後追查或刪除共享上的檔案。Inspect first, land later: nothing reaches the server before the verdict, so there is no after-the-fact cleanup on the share.
  • 使用者無感：對應用程式來說就是一般存檔，不需改變操作或安裝檔案伺服器代理程式。Transparent: to the app it is an ordinary save; no change in user behavior and no agent on the file server.
  • 涵蓋 UNC 與對應磁碟：\\server\share 與對應成 Z: 的寫入都應納入 PoC 驗證。UNC and mapped drives: test both \\server\share and drives mapped as Z: in the PoC.

雲端集中 DLP 檢查Centralized Cloud DLP

內容比對在 Netskope 雲端進行，端點不需要承擔大型偵測引擎的負載。Content matching runs in the Netskope cloud, so the endpoint does not carry a heavy detection engine.

  1. 1一套政策：可沿用租戶既有的 DLP Profile（個資、信用卡號、機密標籤等），與 Web / SaaS 管道標準一致（依授權）。One policy set: reuse the tenant's existing DLP profiles (PII, card numbers, confidential labels) so endpoint and web / SaaS channels share one standard (license dependent).
  2. 2判定回傳：雲端回傳 Block 或 Allow，端點依結果刪除或釋放暫存檔。Verdict: the cloud returns Block or Allow and the endpoint deletes or releases the temp file.
  3. 3需驗證的邊界：大檔案的判定時間、壓縮檔內容、端點無法連雲時的行為，都要在 PoC 中實測。Edges to verify: verdict time for large files, archive contents, and behavior when the endpoint cannot reach the cloud all need PoC testing.

使用者告警與非同步日誌User Alerts & Async Logging

阻擋時在桌面告知使用者原因；事件與稽核紀錄在背景上傳，不影響存檔速度。On block, the user sees why on the desktop; events and audit records upload in the background without slowing the save.

Block

暫存檔刪除、檔案未落地，桌面跳出可自訂的告警訊息，降低客服詢問。Temp file deleted, nothing lands; a customizable desktop alert explains why, cutting helpdesk calls.

SkopeIT

檔名、使用者、裝置、命中規則與動作上傳到雲端 Tenant，可在 SkopeIT / Incidents 查詢與調查。File name, user, device, matched rule and action go to the tenant for search and investigation in SkopeIT / Incidents.
