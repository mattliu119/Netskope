05 · Add a Case

新增案例：下次遇到問題怎麼補進來Add a case: how to record the next issue

兩種做法Two ways
  1. 交給 Claude：把症狀、log、tcpdump、Orchestrator 截圖和最後的修正貼上，請 Claude「新增一筆案例到這個手冊」。它會補進案例、注意事項、指令與收尾清單，並更新這一頁。Ask Claude: paste the symptom, logs, tcpdump, Orchestrator screenshots and the final fix, and ask it to "add a case to this playbook". It adds the case, lessons, commands and wrap-up list and republishes this page.
  2. 自己編輯：在頁面原始碼的 CASES 陣列複製右邊的範本，填入內容；新的注意事項加到 NOTES（cases 填案例 id），新的指令加到 CMDS。Edit it yourself: copy the template on the right into the CASES array in the page source and fill it in; add lessons to NOTES (set cases to the case id) and commands to CMDS.
  3. 外部 IP 一律用示意位址（203.0.113.0/24、198.51.100.0/24、192.0.2.0/24），避免把客戶的真實位址放進共用文件。Use documentation addresses for external IPs (203.0.113.0/24, 198.51.100.0/24, 192.0.2.0/24) so real customer addresses stay out of shared docs.
