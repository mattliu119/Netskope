Netskope One · CASB API · Cloud Exchange

SaaS 資料保護：OneDrive 自動隔離 + Teams 主管決策 SaaS Data Protection: OneDrive Auto-Quarantine + Manager Decision in Teams

不需要在端點安裝 Netskope Client。CASB API 直接與 OneDrive 整合，檔案上傳後偵測到機敏或惡意內容，就自動移到隔離資料夾；同時由 Netskope Cloud Exchange 的 Teams plug-in 發送通知到 Teams 頻道，讓主管在 Teams 上按「同意」或「拒絕」：同意就由 Netskope 透過 API 把檔案還原到原資料夾，拒絕就刪除檔案，所有動作都留下日誌。 No Netskope Client on the endpoint. CASB API connects straight to OneDrive: when an uploaded file contains sensitive or malicious content it is moved to a quarantine folder, and the Netskope Cloud Exchange Teams plug-in posts to a Teams channel where a manager clicks Approve or Reject: approve and Netskope restores the file to its original folder through the API; reject and the file is deleted. Every action is logged.

02 · Key Design

關鍵設計Key Design

無代理，任何裝置都涵蓋Agentless, any device

CASB API 以授權方式連接 Microsoft 365 租戶，不經過使用者的網路。公司電腦、個人裝置、手機，甚至後端程式上傳的檔案，只要進到 OneDrive 都會被檢查；既有檔案也能回溯掃描。CASB API connects to the Microsoft 365 tenant with an authorized connection, independent of the user's network. Files from company PCs, personal devices, phones or backend scripts are all checked once in OneDrive, and existing files can be scanned retroactively.

隔離而不是刪除Quarantine, not delete

命中 DLP 或威脅防護的檔案會移到管理者指定的隔離資料夾，原位置留下說明檔告知使用者。主管同意就還原、拒絕才刪除，避免誤判造成資料遺失。Files that hit DLP or threat protection move to an admin-defined quarantine folder, with a notice file left in place for the user. Approved files are restored and only rejected ones are deleted, so false positives cost nothing.

Cloud Exchange 串接 TeamsCloud Exchange to Teams

Netskope Cloud Exchange 取得隔離事件後，透過 Microsoft Teams plug-in 推送到指定頻道，主管不必登入 Console，直接在 Teams 按「同意」或「拒絕」，Netskope 再透過 API 執行還原或刪除，並記錄日誌。Netskope Cloud Exchange picks up the quarantine event and pushes it to a Teams channel through the Microsoft Teams plug-in, so managers can click Approve or Reject right in Teams; Netskope then restores or deletes the file through the API and logs it.
